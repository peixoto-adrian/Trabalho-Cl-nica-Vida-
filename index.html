Introdução & Objetivos

O projeto Clínica Vida+ é uma solução acadêmica para organização de processos operacionais e lógicos de uma clínica médica. A aplicação integra planejamento ágil, cadastro com tratamento de exceções, validação matemática de consultas, estruturas de dados para recepção e modelagem estrutural UML.


Objetivos do Projeto:

  • Passo 1: Mapear e gerenciar a execução do projeto via Metodologia Ágil (Kanban e Relatório de Sprint).
  • Passo 2: Disponibilizar um módulo interativo para cadastro, busca e estatísticas de pacientes com tratamento de entradas.
  • Passo 3: Validar matematicamente a liberação de consultas usando Tabelas-Verdade de Lógica Proposicional.
  • Passo 4: Demonstrar o processamento sequencial da Fila de Atendimento usando a política FIFO (First-In, First-Out).
  • Passo 5: Modelar as interações entre Secretária, Médico e Sistema com Diagrama de Casos de Uso UML.

Passo 3: Lógica Proposicional e Tabelas-Verdade

Análise do Cenário (A=F, B=V, C=V, D=F):

  • Consulta Normal: Resultado FALSO (Atendimento Negado). Sem agendamento (A=F), exigia-se pagamento em dia (D=V). Como D=F, a expressão retorna Falso.
  • Emergência: Resultado VERDADEIRO (Atendimento Liberado). Na emergência o agendamento é irrelevante. Com médico disponível (C=V) e documento válido (B=V), a liberação é imediata.

Passo 4: Algoritmo e Estrutura de Dados (Fila FIFO)

Abaixo está o pseudocódigo e o simulador funcional da ordem de atendimento First-In, First-Out (FIFO).

Simulação Interativa da Fila

Pseudocódigo Estruturado

Algoritmo FilaAtendimentoClinica
    Tipo Paciente = Registro
        nome : Texto
        cpf  : Texto
    FimRegistro

    Var
        fila : Vetor[1..3] de Paciente
Inicio
    // Inserção na Fila
    fila[1] <- ("João Santos", "111.222.333-44")
    fila[2] <- ("Maria Oliveira", "555.666.777-88")
    fila[3] <- ("Pedro Henrique", "999.000.111-22")

    // Remoção do 1º Paciente (Atendimento)
    Escreval("Atendendo agora: ", fila[1].nome)

    // Reorganização (Shift)
    fila[1] <- fila[2]
    fila[2] <- fila[3]

    // Exibição dos restantes
    Escreval("Aguardando 1º: ", fila[1].nome)
    Escreval("Aguardando 2º: ", fila[2].nome)
FimAlgoritmo
